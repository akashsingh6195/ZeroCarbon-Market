# Replit setup: do this by hand first

1. Create a new Replit App named `zerocarbon-market`.
2. Open the Secrets tool and add these as each one becomes ready:

| Secret | Where it comes from |
| --- | --- |
| `AGENTICORG_BASE_URL` | The hackathon instance's address |
| `AGENTICORG_API_KEY` | AgenticOrg, Settings, API Keys (starts `ao_sk_`) |
| `AGENT_ID_NEED_INTERPRETER` | AgenticOrg agent 01 |
| `AGENT_ID_LISTING_MATCHER` | AgenticOrg agent 02 |
| `AGENT_ID_CLAIM_CHECKER` | AgenticOrg agent 03 |
| `AGENT_ID_CERTIFICATE_WRITER` | AgenticOrg agent 04 |
| `AGENT_ID_ORDER_CONCIERGE` | AgenticOrg agent 05 |
| `AGENT_ID_LAND_SCOUT` | AgenticOrg agent 06 |
| `AGENT_ID_ASK_ZEROCARBON` | AgenticOrg agent 07 |
| `AGENT_ID_COMPLIANCE_GUARD` | AgenticOrg agent 08 |
| `MODELS_API_URL`, `MODELS_API_KEY` | The models service from Claude Code |
| `INTERNAL_KEY` | Any long random string; the same value goes in the models service's `.env` |
| `ADMIN_PIN` | Any number you choose |

3. Upload `00-shared/contracts.md` into the app as `shared/contracts.md`. When Claude Code has made the JSON schema files, copy `zerocarbon-models/contracts/*.json` into `shared/contracts/`.
4. Paste prompts `01` to `09` into Replit Agent one at a time. Run each prompt's check before the next.
