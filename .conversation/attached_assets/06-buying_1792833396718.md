Build buying, the order tracker and the certificate.

1. Buy, then choose tonnes, then a box: "How will you describe this purchase?"
2. Route POST /api/claim-check calls agenticorg.run(AGENT_ID_CLAIM_CHECKER, ...). Show allowed_wording and any flagged phrases before payment. If it fails, show "We retired N tonnes of ... credits from ..., vintage ...".
3. A demo payment screen: "Demo payment. No money moves." and a Pay button.
4. Create the order, and an order tracker page that shows stages like a parcel tracker:
   - Voluntary: Order placed, Payment held, Transfer started, Credits delivered, Retired, Certificate ready.
   - India offset: Order placed, Bid prepared, Monthly session, Credits delivered, Retired, Certificate ready.
   - For the demo, move one stage every 3 seconds.
5. A certificate page with a shareable link: the text from AGENT_ID_CERTIFICATE_WRITER, project, tonnes, vintage, demo serial numbers, and the Demo data chip in large type. If the agent fails, use a fixed template. The certificate never says the buyer is zero carbon or carbon neutral.
6. On each order page, a "Question about this order?" box that calls AGENT_ID_ORDER_CONCIERGE. When escalate is true, save it in events for the admin page.

Log "order" and "retired" events.

Check before moving on: one tonne goes from Buy to a shared certificate in under 40 seconds on a phone.
